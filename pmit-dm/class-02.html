এক নজরে: ৬টা Data Mining Task
TaskTypeএক লাইনেউদাহরণ
ClassificationPredictiveলেবেলসহ ডেটা থেকে শিখে নতুন রেকর্ডের class বলাFraud, churn, direct marketing
RegressionPredictiveএকটা continuous সংখ্যা অনুমানবিজ্ঞাপন খরচ → বিক্রি
Deviation DetectionPredictiveস্বাভাবিকের চেয়ে অস্বাভাবিক কিছু ধরাCard fraud, network intrusion
ClusteringDescriptiveলেবেল ছাড়া মিল অনুযায়ী দলে ভাগMarket segmentation, documents
Association RuleDescriptiveকোন item একসাথে আসে, rule বানানো{Diaper, Milk} → {Beer}
Sequential PatternDescriptiveসময়ের ক্রমে কোন ঘটনার পর কোনটা(Shoes)(Racket) → (Jacket)
